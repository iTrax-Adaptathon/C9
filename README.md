# MeetWise

MeetWise is a beginner-friendly smart meeting management website built using HTML, CSS and JavaScript.

## Features

- Dashboard with meeting statistics
- Create, edit and delete meetings
- Search and filter meetings
- Accept/decline meeting invitations
- Smart meeting-platform recommendation quiz
- Community creation and suggestions
- Profile and platform preferences
- Light/dark mode
- Browser localStorage persistence

## How to run

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Either double-click it, or use the VS Code "Live Server" extension.

No backend or database installation is needed for this prototype.

## Important

This version uses browser localStorage, so it is ideal for a mini-project/demo/prototype.
For a full multi-user project, you can later connect it to Java/Spring Boot, Node.js, PHP, Firebase, MySQL, etc.
